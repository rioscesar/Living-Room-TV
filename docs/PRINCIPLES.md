# Product Principles

1. **Couch first:** controls and type must work at television distance.
2. **Obvious focus:** users should always know what will activate.
3. **Entertainment first:** normal use should not expose Windows configuration.
4. **Local first:** the shell loads without a backend, account, telemetry, or cloud sync.
5. **Deterministic behavior:** navigation and launch boundaries are explicit and testable.
6. **Low maintenance:** app configuration should not require layout changes.
7. **Progressive enhancement:** optional integrations must not make the base dashboard fragile.
8. **Evidence before claims:** hardware and visual behavior are reported only when actually tested.

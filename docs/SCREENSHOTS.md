# Screenshot Guidance

Screenshots are optional documentation and are not a release requirement. No screenshot is committed for the initial candidate because development views may contain personal recent history or local Favorites.

Before adding a screenshot:

1. Use a clean browser profile and a fresh clone without `favorites.local.js`.
2. Clear `livingRoomTv.recents` from browser local storage.
3. Confirm no usernames, notifications, tabs, bookmarks, account avatars, URLs, or Windows chrome are visible.
4. Capture the dashboard at 2560×1440 or 3840×2160 in Chrome F11.
5. Keep initials as the app identity; do not import third-party logos.
6. Review the image metadata and pixels before committing under `assets/screenshots/`.
7. Record the capture environment and revision in the pull request.

A screenshot is documentation evidence, not proof of controller, couch-distance, or streaming-site behavior.

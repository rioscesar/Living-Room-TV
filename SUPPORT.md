# Support

Start with the troubleshooting section in `README.md` and run the project checks. When opening a support issue, include the Windows version, browser version, Steam/controller setup, exact steps, and sanitized command output.

Do not attach personal Favorites, browser history, credentials, local usernames, full filesystem paths, helper logs containing sensitive context, or account details. Reduce examples to safe placeholders.

Feature requests, ordinary defects, and sanitized security reports may use GitHub Issues. Issues are public. Follow `SECURITY.md` and never post credentials, personal information, private destinations, browser data, or unsafe exploit details.
